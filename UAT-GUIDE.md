Run on the owner's PC/WSL, keep terminal open:

```bash
ssh -i ~/.ssh/myeduprojects.pem -N -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:5680:127.0.0.1:5680 myeduprojects@34.173.234.206
```

Open localhost5680 in a private/incognito window. Complete the fresh n8n owner setup with your own private password. It is an editor-only login. No existing credentials/users/workflows were copied. ## Stage1 — UI and free discovery

1. Create a new inactive workflow: **Manual Trigger → Voicely Studio**. Keep Studio node runtime version2.
2. Inspect Resource: Agent, Call, Delivery, Speech, Subscription, Tool, Voice. A framework-added **Custom API Call** may also appear; it is generated by n8n and is not a second regular node. Search must show Studio and Agents Trigger, not the removed standalone Agents action.
3. Select **Voice → Get Many**. Choose/create **Voicely Studio API** credential. Service URL: `https://n8n-suite-dev.tryvoicely.com`. Use a staging-issued key with credential/account read, voice read and model catalog read scopes. Do not use a production key or the legacy URL for StudioV2.
4. Return All=OFF, Limit=3. Page Size must be absent. Options should contain Request Timeout and voice Simplify. Execute once: up to3 authorized voice items, no generated audio and no synthesis charge. Toggle Return All=ON and confirm Limit disappears; no need to execute the full list yet.
5. Change Resource to **Agent → Get Many**. The credential selector should now use **Voicely Agents API**, same staging Suite URL, with `agents/read` and other needed scopes. Return All=OFF, Limit=3. Execute once: up to3 accessible agents; an empty list can be valid for an account with no staging agents.
6. Select **Call → Get** without executing. Required Call ID is visible; Include Shared Data is inside Options. Unrelated Voice picker and Simplify controls must not appear. No need to expose private IDs in chat.
7. Select **Speech → Text to Speech** without executing. Check Voice/Text/output binary fields and Additional Options for model/format/language. Operation Identity and Request Timeout belong under Options. New streaming selection is deferred; saved transport behavior remains compatible. Credential returns to Studio API.
8. Add **Voicely Agents Trigger** to a separate inactive workflow. Agent is the required field. Include Setup Test Events and Request Timeout appear under Options. Do not activate/listen yet.

Record each result as PASS/FAIL with operation, runtime version, staging Service URL, safe error code and approximate UTC time. Never share keys, cookies, webhook secrets, audio, transcripts or private IDs.

| --- | --- |

Verify node identity/wiring/resources and moved Options. Do not alter the original. |
| Tool register/disable, redelivery, revoke, setup events | Writes or external-workflow side effects. Not part of first discovery pass; require an explicitly agreed disposable staging fixture. |
| Trigger webhook | Real callback is **not configured** for this loopback-only editor. A tunnel to the editor is not a reachable public HTTPS callback. Do not reuse the old editor's callback path or activate the trigger. Separate staging-only callback routing and disposable registration scope must be agreed first. UI and offline signature tests are available now. |
| HTTP/WS TTS, STT, STS, voice clone | Not automatically executed. These can consume real provider calls, credits or create profiles. Agree bounded staging inputs/call count first. The separate intermittent backend STT timing issue remains open; a failure here is not automatically a node-package regression. |

## Recovery and boundaries

No existing editor/process/database/package was replaced. Stop only the new review editor if needed:

```bash
pm2 stop voicely-n8n-review-v021-dev
```

Do not stop all processes. Original editor remains localhost5678. New editor's synthetic local SQLite store/encryption configuration belongs only to this UAT runtime. No production DB/config/key was copied; production not accessed. No PM2 save/startup configuration, nginx, DNS, billing, provider limits or product services changed. The new editor is intentionally not guaranteed across a VM reboot.
