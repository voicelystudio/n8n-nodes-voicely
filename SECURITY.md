# Security policy

Please report a suspected vulnerability privately to **administrator@tryvoicely.com** and do not open a public issue for it. Include the package version, the affected node or credential, and the steps to reproduce.

We aim to acknowledge reports within three working days. Fixes ship in a new npm version of `@voicelystudio/n8n-nodes-voicely`.

Never include API keys, webhook secrets or customer data in a report.
